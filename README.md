# Balatro-Vita-modding-


A guide to simple modding for the game Balatro on the PSVita


Reqruirements
Balatro-Vita  https://github.com/Daexxxx/Balatro-Vita
You need to own the game
rePatch-reLoaded https://github.com/SonicMastr/rePatch-reLoaded
Winrar or any other archive program that can unzip and make zips


**Step 1** if you dont have the game installed do that first instructions are on the Github for the port
**Step 2** Take the game.love file and rename it to game.love.zip
